# Publication-copy changes

These changes apply only to this new folder. The source workspace, server, frozen historical configurations and results were not changed.

1. Copy only the dependency closure of the documented current experiments plus the complete core, required inputs and A2A/proof sources. Omit machine-generated results and redundant proof intermediates.
2. `rq2_v2/author.py` and `suite.py`: locate MongoDB using `RQ2_MONGOD` or `PATH`, instead of a private server directory. The original SAGA archive is byte-identical. The public suite exposes the current `flow` group only; GReDAC-only groups 2/3 use `rq2_later`.
3. `rq3_retest.credential`: retain environment/file credential loading but require an explicitly configured path instead of falling back to a private home directory. Prompts, retry bounds, inputs, tools and protocol semantics are unchanged.
4. The RQ4 wait-data file retains all sampled values, rules and evidence hashes; source path labels become project-relative. `rq4_full_40g` retains source/schedule/parameter checks, but its publication freeze does not require the original server's exact executable path/hostname. Each new run still records its actual environment.
5. The RTT runtime sample pool is unchanged. Its smaller packaging manifest lists the included public pool/quality files rather than unavailable raw downloads. The original data-freeze SHA256 is retained.
6. Regenerate **publication-only** checksum baselines after curation. They must not be substituted into historical experiment directories. Regression and pilot gates remain in place. A successful old private pilot cannot authorize a newly packaged full RQ3/RQ2 run.
7. Proof replay locates Tamarin/Maude through explicit environment variables or `PATH`. Models, saved certificates, reference mathematics and state transitions are unchanged. Large generated SMT files are reconstructed before replay.
8. A2A hooks are applied only by an explicit separate-copy tool. Main-tree protocol logic is unchanged. Core docstrings, the package import name and source-manifest paths were updated. Unused self-written comparator dispatch and its optional PQ transport were removed; requesting that unshipped transport now fails explicitly. The retained legacy fixed-response handler computes the identical 256-byte result locally instead of importing the excluded comparator. Current RQ2 uses the separate `fixed` handler.
9. Public documentation, comments, experiment method labels and generated report titles now use **GReDAC**, with **RDF** as the structure name. The package distribution name is `gredac-prototype`, and the implementation/import package is `gredac`. New experiment records use `GReDAC`; historical result files are not rewritten. Protocol/domain constants and proof identifiers remain stable as listed in `NAMING.md`. Own environment keys and six helper modules were renamed consistently. Naming changes do not constitute fresh verification of the latest manuscript.
10. The implementation directory was renamed to `gredac/`. Experiment/A2A imports, module-derived timing labels, source-snapshot paths, package discovery and checksums were migrated together. There is no old-package alias in the public copy. Original projects remain at their original paths. Historical provenance retains truthful source locations. These namespace and metadata changes do not change protocol messages, safety checks, persistence or communication.

11. Current RQ2 flow regression now checks the actual 36-run matrix, not the superseded multi-group matrix. Standalone RQ4 A/B defaults end at 256 services; D defaults to eight services, matching the documented frozen plan. Explicit current full schedules are unchanged. Added the test-only RQ3 feasibility fixture required by its offline regression; real model runs never import this fixture.

12. RQ4 orchestration regression checks the current fixed 39-attempt plan; the historical scheduler CLI is disabled to prevent accidental use of its superseded matrix. RQ3 baseline-check labels report the actual packaged file count. The wheel packages only the core library; experiments must run from the complete source checkout so their non-Python inputs and frozen manifests are present.

13. Add the author's chosen MIT license, the missing offline RQ3 test fixture and the existing Z3 binding's setuptools dependency. The A2A supplement accepts the actual completed regression directory and verifies the schedule count declared by that run; it no longer hardcodes a private directory layout. Default larger race parameters are retained, with explicit bounded parameters available for QA.

The detailed source-versus-copy hashes are in `provenance/FILES.json`. `CHECKSUMS.json` protects this entire packaged tree. These are packaging integrity checks, not new experimental measurements or a claim that every dependency has been installed and every end-to-end experiment rerun.
