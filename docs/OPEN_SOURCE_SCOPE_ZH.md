# 最小开源范围与 SAGA 的对应关系

2026-11-17 核对 [SAGA 官方仓库](https://github.com/gsiros/saga)、[实验目录](https://github.com/gsiros/saga/tree/main/experiments)、[证明目录](https://github.com/gsiros/saga/tree/main/proofs) 和 [A2A 分支](https://github.com/gsiros/saga/tree/a2a)。官方公开的主要材料是协议实现、Agent 业务示例、合成测试数据、配置与依赖、运行说明和证明工件；A2A 是独立分支。并未据此假定官方公开了每次实验的全部原始数据库。

据此，本副本只保留让读者理解实现、运行当前实验、复核证明所需的材料：

| 必须保留 | 本副本内容 | 原因 |
|---|---|---|
| 完整核心 | `gredac/`，实际网络参与方与共享客户端 | 能检查安全检查、持久化和实际角色边界，不能仅开源实验壳 |
| 当前实验入口 | RQ2 三部分、分配策略 v2、RTT；RQ3 三场景；RQ4 A/B/D | 能按现用配置复现，不保留旧轮次作为另一套推荐入口 |
| 必要输入 | 75 个正式业务实例及开发数据、分配需求清单、RQ4 等待分布、RIPE RTT 样本 | 输入与随机种子可核验；不需公开凭据或所有 API 轨迹 |
| 独立 A2A 扩展 | 桥接模块、回归/故障入口、核心小补丁及 SDK 依赖 | 有实现可运行，同时保留与论文性能版本的界限 |
| 测试与证明 | 相关回归、GReDAC 证明源和证书、SMT 生成器 | 检查代码和模型；生成型大型 SMT 文件由脚本重建 |
| SAGA 原源码对照 | 固定 commit 的原 ZIP、逐文件哈希、许可证和运行适配器 | 对照确实运行作者代码，不能以自行复现冒充 |
| 使用与溯源 | 安装、运行说明、哈希、第三方说明 | 移植和核验所必需 |

**不放入开源包**：历史源码/配置备份、被替代的完整实验套件、旧计划和聊天记录、论文草稿、服务器与 SSH 配置、API 密钥、虚拟环境和二进制依赖包、运行生成的证书/私钥、完整 SQLite/MongoDB 状态、逐轮 LLM 请求响应、全部监控日志、全量原始结果归档，以及可由生成器重建的约 400 MB SMT 中间文件。它们仍留在原工作区/服务器，未删除。

不复制整个 `final-experiment-results`。本包包含生成新结果和统计结果的代码；原始论文证据仍由原归档保存。如投稿的工件要求另行提供数值结果，可单独发布脱敏、按独立运行汇总的数据包，不能把只发布代码称为已发布完整原始证据。

保留现用代码直接导入的共享依赖，名称已统一。纳入原因在 `provenance/INCLUSION_REASONS.json`；不是额外推荐的历史实验。未使用的 `native_*` 自写对照已移出开源副本，不提供 MAGIQ 编译依赖或运行入口；原始工作区仍完整保留这些历史代码。

初次整理只进行了包装检查；最终检查另在隔离 Linux 副本执行非 LLM 回归和最小功能样例，不作为新论文性能数据。公开名称统一为 GReDAC，结构名为 RDF，实现包为 `gredac/`。协议逻辑、消息及密码学常量不变。具体修改见 `PORTABILITY_CHANGES.md`，内部旧标识的保留原因见 `NAMING.md`，实际验证范围见 `FINAL_CHECK_ZH.md`。

注意：没有复制完整原始结果，不代表没有任何自建或实测数据。当前仍包含自建任务输入、供 RQ4 采样使用的 RQ3 实测时长，以及已有证明检查结果，逐项见 `DATA_INVENTORY_ZH.md`。本轮更名未改变这些数据。作者已选择 MIT 许可，详见根目录 `LICENSE`；第三方源码和外部数据保留各自条款。
